# السكربتات المحلية — كيف تشغّلها بدون أسرار في الكود

السكربتات في `scripts/` لا تحتوي على أي بريد أو كلمة مرور أو مفتاح.
كل الأسرار تصل من **متغيّرات بيئة** في جلستك فقط.

## 1) اضبط متغيّرات البيئة مرة واحدة لكل جلسة PowerShell

```powershell
$env:LEARNLAW_SUPABASE_URL      = "https://<project>.supabase.co"
$env:LEARNLAW_SUPABASE_ANON_KEY = "<publishable key>"
$env:LEARNLAW_ADMIN_EMAIL       = "<admin email>"
$env:LEARNLAW_ADMIN_PASSWORD    = "<admin password>"
```

- هذه المتغيّرات تعيش في الذاكرة فقط. إغلاق النافذة يمسحها.
- لا تكتبها في ملف، ولا في `.env` داخل المشروع، ولا في التيرمنال الذي تُسجّله.
- يفضّل استخدام حساب **اختبار** وليس حساب الأدمن الحقيقي عند التجربة.

## 2) السكربتات المتاحة

| السكربت | الوظيفة | أسرار مطلوبة |
|---|---|---|
| `check_subs.ps1` | يسرد التصنيفات والأقسام الفرعية | كل الأربعة |
| `list_cats.ps1` | يسرد الأقسام الفرعية كـ JSON | كل الأربعة |
| `import_case.ps1` | يستورد قضية من ملف JSON | كل الأربعة |
| `import_case_md.ps1` | يستورد قضية من ملف Markdown | كل الأربعة |
| `_audit_real.mjs` / `_check_soft.mjs` | تدقيق للقراءة فقط | حسب محتوى الملف |
| `verify_aab.ps1` | يتحقق من توقيع الحزمة | لا شيء |
| `verify_upload_keystore.ps1` | يتحقق من مفتاح التوقيع | لا شيء |
| `backup_upload_keystore.ps1` | نسخة مشفّرة من المفتاح | كلمة مرور النسخة |
| `restore_upload_keystore.ps1` | استعادة المفتاح من النسخة | كلمة مرور النسخة |
| `release_preflight.ps1` | فحص شامل قبل الرفع | لا شيء |

## 3) تحذير

هذه السكربتات تكتب على **قاعدة الإنتاج** (import_case وما شابه). قبل تشغيل
أي منها:

1. تأكد أن متغيّرات البيئة تخصّ المشروع الصحيح.
2. خذ نسخة احتياطية أو استخدم فرع قاعدة بيانات (Supabase Branch).
3. شغّلها بأقل صلاحية ممكنة، بحساب اختبار.
